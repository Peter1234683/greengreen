# 그린토피아(GreenTopia) MVP — 마일스톤 1 구현 계획

AI 기반 민간 그린리모델링 공동공사 플랫폼 **그린토피아(GreenTopia)**의 1단계 기본 뼈대, 대구 시드 데이터, 데이터 모델 및 듀얼 역할 온보딩 구현 계획입니다.

---

## 1. 개요 및 설계 원칙

- **핵심 가치**: "혼자 고치면 비싸고, 모아 고치면 싸다" (AI는 묶어주고, 시장 입찰은 가격을 결정)
- **런타임 아키텍처**: React + TypeScript + Tailwind CSS (Vite SPA) + Express 백엔드(`server.ts`, Port 3000)
- **외부 연동 어댑터 패턴**: 건축물대장 및 에너지 진단(GR-AI)을 위한 추상화 인터페이스와 모의(Mock) 어댑터 구축
- **UI/UX 원칙**: 한국어 생활 언어 중심, 모바일 터치 인체공학(44px+ 터치 타깃, 15% 스티키 캡, 무결점 하단 탭 내비게이션), 제로-필(Zero-Pill) 타이포그래피 정돈

---

## 2. 제안 구현 상세 (마일스톤 1)

### A. 공통 데이터 모델 및 타입 정의 (`src/types/greentopia.ts`)
1. **User & Auth**:
   - 역할(Role): `customer` (일반 고객/건물주) | `contractor` (시공업체) | `admin` (운영자)
   - 세션 정보, 인증 상태, 프로필
2. **Building & Registry**:
   - 주소, 대지위치, 사용승인일, 건물구조(조적조, 철근콘크리트, 목구조 등), 용도(단독, 다가구, 다세대), 연면적, 층수, 세대수
   - 에너지 성능 간이 등급(1~7등급), 노후도, 최근 전기/가스 요금 추정치
   - 거주자 체감 수요 태그 (창호 노후, 겨울철 외풍, 냉난방비 과다, 보일러 교체 등)
   - 희망 공사시기, 예산 범위, 공동공사 참여 동의 상태, GPS 좌표 (위경도)
3. **Contractor Profile & PQ**:
   - 상호명, 대표자, 사업자등록번호, 연락처, 활동 권역(대구 중구/동구/서구/남구/북구/수성구/달서구/달성군 등)
   - 시공 가능 공종 (고단열 창호, 외벽단열, 지붕단열, 바닥/내단열, 고효율 콘덴싱 보일러, 환기설비)
   - GR 사업자 등록 여부 및 증빙 상태, 건설업 면허 번호, 하자보증 이행증권 발급 가능 여부
   - 심사 상태 (`pending` 심사 대기 | `approved` 승인 | `rejected` 반려)
   - 대표 시공 실적 및 고객 평판 점수(품질, 공기, 청결, 소통, A/S, 가성비)
4. **Cluster & Co-Construction**:
   - 클러스터 ID, 대표 공종, 참여 건물 목록, 평균 적합도, 반경, 상태 (`gathering` 모집중 | `bidding` 입찰중 | `awarded` 낙찰 | `in_progress` 시공중 | `completed` 완료)
5. **Bid & Review**:
   - 입찰 제안 구조, 종합평가 점수표, 공종별 ㎡ 단가, 하자 후속 리뷰 모델

### B. 대구 가상 시드 데이터 구축 (`src/data/daeguSeedData.ts`)
1. **대구 노후 저층주택 100동**:
   - 대구 8개 구·군(중구 남산동·대봉동, 남구 대명동·이천동, 서구 비산동·평리동, 북구 침산동·복현동, 동구 신암동·효목동, 수성구 범어동·만촌동, 달서구 송현동·두류동 등) 실재 지번 기반 분포
   - 1980~2015년 사용승인 노후 단독/다가구/다세대 건물 프로필
   - 건축물대장 표준 스펙, 고지서 데이터, 개선 희망 공종, 좌표 세트
2. **전문 시공업체 15곳**:
   - 대구·경북 권역 GR 인증업체 및 전문 건설사 (창호 전문, 종합 단열 전문, 보일러/기계설비 등)
   - PQ 1차 승인 상태 12곳 + 심사 대기 3곳 (온보딩 및 관리자 승인 테스트용)
3. **완료 공사 및 사전 리뷰 8건**:
   - 실제 시공 전후 절감 효과 및 세부 평판 리뷰 데이터

### C. 어댑터 인터페이스 및 서비스 레이어 (`src/services/`)
1. **`BuildingRegistryAdapter`**:
   - 주소 검색 시 건축물대장 데이터 반환 (현재 시드 데이터 기반 목 어댑터, 향후 공공데이터포털 API 연동 준비)
2. **`EnergyDiagnosisAdapter`**:
   - 간이 진단 모드 (연식·구조·연면적 기반 에너지 효율 등급 및 예상 절감량 산출)
   - 외부 링크 모드 (GR-AI 플랫폼 https://grai.ibed.cloud 안내 슬롯)
   - API 연동 TODO 슬롯
3. **`StorageService`**:
   - 브라우저 로컬 스토리지 및 Express 서버 연동으로 사용자 등록 정보, 건물 정보, 클러스터 상태 영속화

### D. 듀얼 역할 온보딩 및 홈 경험 (`src/components/onboarding/`)
1. **스플래시 & 인트로**:
   - 서비스 핵심 슬로건: "혼자 고치면 비싸고, 모아 고치면 싸다"
   - 직관적인 그래픽과 그린리모델링 공동발주 혜택 안내
2. **회원 유형 선택 카드 (2개 대형 카드)**:
   - 🏠 **"내 집을 고치고 싶어요" (일반 고객/건물주)**:
     - 3단계 빠른 가입: 기본 정보 → 내 건물 주소 등록(대구 시드 연동 검색) → 공사 수요 태그 선택
   - 🛠️ **"공사를 수주하고 싶어요" (시공업체)**:
     - 4단계 전문 가입: 회사 정보 → 시공 가능 공종/권역 → GR 등록·면허·하자보증 정보 → 가입 후 "심사 대기" 상태 전환 안내
3. **역할 전환(Role Switcher) 디버그 툴바**:
   - 상단 헤더에 개발/시연용 빠른 전환기 배치 (고객 뷰 ↔ 사업자 뷰 ↔ 관리자 뷰 ↔ 온보딩 재체험)

### E. 모바일 우선 PWA 레이아웃 및 내비게이션
1. **PWA 웹 앱 매니페스트 및 서비스 워커**:
   - `public/manifest.json`, 아이콘, `usePWAInstall` 훅을 통한 홈 화면 추가(설치) 버튼 구현
2. **고객 전용 모바일 뷰**:
   - 상단 헤더 (그린토피아 로고 + 알림/역할 전환)
   - 반응형 하단 탭 내비게이션 (홈 / 내 집 진단 / 공동공사 / 내 공사 / 마이)
   - 대구 100동 노후주택 현황 요약 카드 및 주변 공동공사 수요 탐색 진입로
3. **사업자 전용 모바일/데스크톱 뷰**:
   - 심사 대기 안내 배너 (승인 전 입찰 제한 안내) 및 승인 후 수주 공고 탐색 대시보드
4. **관리자 기본 승인 뷰 (MVP)**:
   - 시공업체 PQ 심사 대기 목록 확인 및 [승인] / [반려] 기능

## 3. 검증 계획

### 자동 빌드 및 린트 검증
- `npm run build` 및 `compile_applet` 실행으로 TypeScript 타입 에러 및 Vite 빌드 성공 검증
- `npm run lint` 실행으로 구문 오류 및 사용되지 않은 모듈 검증

### 사용자 시나리오 기반 수동 검증 흐름
1. **온보딩 검증**:
   - 앱 최초 접속 시 스플래시 및 2종 카드(일반 고객 vs 시공업체) 노출 확인
   - 고객 가입 폼 진행 시 대구 주소 자동 완성 및 생활 언어 수요 태그(창호, 외풍 등) 선택 동작 확인
   - 시공업체 가입 시 GR 면허/공종 선택 후 "심사 대기" 상태로 전환되는지 확인
2. **역할 라우팅 검증**:
   - 상단 역할 전환기를 통해 [고객 뷰] 전환 시 5개 하단 탭(홈, 진단, 공동공사, 내 공사, 마이) 정상 렌더링 확인
   - [사업자 뷰] 전환 시 수주 및 심사 상태 화면으로 분기되는지 확인
   - [관리자 뷰] 전환 시 신규 가입 시공업체를 1클릭으로 승인 처리하여 즉시 상태가 동기화되는지 확인
3. **시드 데이터 로드 검증**:
   - 대구 100개 노후 주택 및 15개 시공업체 정보가 정상 로드되고 검색/필터링 가능한지 확인
4. **PWA 설치 지원 검증**:
   - 인앱 설치 버튼 렌더링 및 모바일 뷰포트에서 레이아웃 깨짐(오버플로우, 터치 타깃 부족) 없는지 확인
